# Практическая №3 — Сетевая боевая система (PvP)

Это продолжение второй практической (Unity 6000.4.6f1 + Node.js + NativeWebSocket).
**Ветка `pr3` содержит код третьей практической; исходный `main` не изменён.**

## Быстрая настройка (один раз)

1. Откройте проект Unity **из ветки pr3** (не из main), дождитесь импорта скриптов.
2. В верхнем меню выберите **Tools → PR3 → Собрать боевую сцену**.
3. Команда автоматически настроит `GameScene`, `NetworkPlayer`, `LocalPlayer`, `Projectile_Visual`, материал снаряда, UI здоровья/смерти и привяжет ссылки на компоненты.
4. Убедитесь, что в Console нет красных ошибок, и сохраните проект.
5. Откройте терминал в `Assets/MazeServer` и запустите сервер: `node server.js` (при отсутствии зависимости сначала `npm install`).
6. Запустите Unity через `LobbyScene` и подключите два клиента к одному серверу.

## Управление

- WASD — движение, мышь — обзор
- Пробел — прыжок, Ctrl — приседание
- ЛКМ — ближний удар (-25 HP, до 2.2 м, сектор 90°, кулдаун 0.6 сек)
- ПКМ — дальний выстрел (-20 HP, скорость 18 м/с, кулдаун 0.5 сек)
- После гибели — 3 секунды до возрождения, восстановление 100 HP

## Что добавлено

- Компоненты: CombatHUD, MeleeAnimator, VisualProjectile, ProjectileManager, DamageFlash, NetworkPlayerVisualFeedback.
- Обработка боевых пакетов в NetworkClient: ATTACK_MELEE, FIRE_RANGED, HIT_EVENT, PLAYER_DIED, PLAYER_RESPAWN, SPAWN_PROJECTILE, DESTROY_PROJECTILE.
- Серверная проверка дальности/сектора атаки, кулдаунов, здоровья и попаданий снарядов в стены/игроков.
- Исправлена недоработка второй практической: обработка SNAPSHOT/PLAYER_LEFT в NetworkClient.

## Проверка

1. Два клиента видят друг друга, ники и миникарту.
2. Удар с расстояния > 3 м не снижает HP.
3. Удар в спину или сбоку не снижает HP.
4. Четыре попадания ЛКМ — смерть, +1 победа атакующему.
5. Через 3 секунды игрок появляется снова со 100 HP.
6. Выстрел ПКМ виден обоим, снаряд исчезает от столкновения и наносит 20 HP при попадании.
7. При получении урона — вспышка экрана и окрашивание модели другого игрока.

**Важно:** Unity Editor не запускался автоматически при подготовке репозитория; окончательная проверка импорта, отображения и сетевого PvP должна выполняться в Unity.
